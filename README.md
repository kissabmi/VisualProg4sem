## Приложение ToDoList React+TS.

#### Функционал:

* Добавить задачу
* Удалить задачу, изменить статус
* Фильтры "все", "", ""
* Поиск по названию и описанию

#### Формат задачи: (task.ts)
- id (number)
- name (string)
- description (string)
- status (true/false т.е выполнено или нет)

### Пошаговый план работы
1. Создать пустой index.html и подключить React/Babel.
2. Написать базовый компонент App и вывести "Hello World".
3. Добавить стейт tasks с парой фейковых задач, чтобы было что выводить.
4. Сделать вывод задач (написать компонент TaskItem и map).
5. Сделать форму добавления (чтобы задачи начали добавляться).
6. Прикрутить удаление и чекбоксы.
7. В самом конце сделать поиск и кнопки фильтров.
