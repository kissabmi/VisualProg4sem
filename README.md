# Домашнее задание №7

**Задание выполняется в ветке `lab7`**

## Описание

Создать компонент React `BookCard`, в котором отображается информация о книге (сверху вниз):
1. Обложка
2. Название
3. Авторы

**Требования к оформлению и реализации:**
- Шрифт названия книги должен быть больше, чем шрифт у авторов.
- Данные в карточку должны приходить через пропсы (`props`).
- Изображение обложки должно приходить в виде набора байт (`BLOB`).
- Приложение должно расположить карточки книг горизонтально (в ряд). Если карточкам не хватает места, то оставшиеся должны переноситься на следующие строки.

## Источники данных (API)

Реализовать демонстрационное приложение на React. Приложение должно получать данные о книгах по API:
`https://fakeapi.extendsclass.com/books`

**JSON схема ответа API книг:**
```json
[
  {
    "id": 123,
    "title": "string",
    "isbn": "string",
    "pageCount": 123,
    "authors": ["string"]
  }
]
```

### Дополнительное API для обложек

Поскольку основной API не предоставляет изображения обложек книг, их следует получать через Google Books API:
`https://www.googleapis.com/books/v1/volumes`

Для получения изображения в URL запроса необходимо передать параметр `q` — критерий поиска. 
*Например*, запрос на поиск по `isbn` (уникальный идентификатор книги) для книги "Specification by Example" выглядит так:
`https://www.googleapis.com/books/v1/volumes?q=isbn:1617290084`

Ссылку на саму миниатюру картинки (thumbnail) можно получить из ответа по следующему пути:
```javascript
items[0].volumeInfo.imageLinks.thumbnail
```
